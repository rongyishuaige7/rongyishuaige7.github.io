# 证据刷新与动效调整

## 目标与范围

保留 Astro 静态站、三条线、单深色主题、现有 URL、导航与品牌。分两次交付：先修正证据采集和标签，再调整首屏、截图和筛选动效。不增加框架、动画库或外部服务。

## 证据

- Hardware Lab 索引明确记录指定工作流；首页部署时逐项核对公开性、默认分支 HEAD、索引 SHA、固定运行与最新可信运行。任何未知、漂移或失败都保留非绿色结果，项目介绍仍可浏览。
- CI 允许 push、workflow_dispatch、schedule，排除 PR、其他分支和其他工作流。按实际运行开始时间选择最新结果，不能回退到较早的成功。
- Web、扩展、插件、固件与索引检查分别命名，避免把 Web 构建理解成原生桌面验证。
- 快照超过预期刷新周期时显示采集延迟；不按年龄判定未变化 HEAD 的 CI 失效。Artifact 在到期、页面恢复和重新可见时复核。
- npm 下载数据单独失败时显示 partial，不使用上次数据。

风险：外部 API 可能失败或限流。数据采集保持有限重试、明确降级；采集器测试使用注入的 API 复现部分失败，避免靠实时网络覆盖错误分支。

## 动效

- 首屏按 Yi盘、Agent 工具、硬件的顺序传递信号，文字和 CTA 及时可读；装饰循环离屏或切后台时暂停。
- 真实 DSH 截图保持可读。图像解码后仅进行一次短扫描，不让持续扫描线看起来像真实产品数据。
- 硬件筛选使用原生 Web Animations 的位置过渡；先完成筛选语义和可访问状态，再动画化视觉变化。快速连续点击以当前屏幕位置为起点，避免旧动画覆盖新状态。
- 章节进入保持轻量、逐步展开；读取进度使用 CSS scroll timeline，章节高亮使用 IntersectionObserver。保持正常浏览器滚动。
- reduced-motion 在初始加载和系统设置变更后均有效。无 JavaScript、无动画 API 或初始化失败时保留可读内容与可用链接。

风险：动画与布局测量可能冲突。位置动画只操作外层磁贴 transform，卡片 hover 使用内层；读取位置集中在更新 DOM 前后，避免逐项读写交错。所有监听器、观察器、计时器和动画都可清理。

## 配色、真实画面与动效（2026-10-20）

用户保留 Hardware 绿与 Yi盘橙，认为 DSH 与开发工具区配色不协调，并对示意图、卡片和动画不满意。审查实测的原因：DSH 截图为浅色主题；截图费用橙与 carry-2 的 ΔE2000 为 2.1；see-2 的明度与色相走向与另外两条线相反；`--ok` 与 `--touch` 同值；`--danger` 与 carry 的 ΔE 为 9.8；首屏橙色光斑落在 DSH 与硬件卡之间。

范围：

- 配色：see-2 改为 `#63ccf8`，与 carry、touch 一样变亮并转向黄绿。状态与线色分离：实心点表示通过或已发布（颜色跟随所在线），空心环表示未核验或未知，玫红 × 表示失败，琥珀表示过期或采集延迟。光斑对齐三张入口卡。
- DSH 截图：使用 dsh-stats 自带深色主题与 showcase 夹具（项目名为占位）重新截取总览、时间线（Token 柱）、趋势三张，作为新文件保存，不覆盖旧截图。
- 真实画面：硬件磁贴使用各仓库已公开、已去除 EXIF/GPS 的历史照片，按 Hardware Lab `media_scope` 标注拍摄日期或“未注明日期”；未公开实物照片的项目明确标出。照片缩放后放进 `src/assets`，由 `astro:assets` 输出 WebP。
- 动效：Yi盘章节改为按 README 事实绘制的盘内闭环流转；DSH 窗口在三张真实截图间轮换，可暂停；首屏入口进入视口时播放一次，桌面悬停可重放；页头提供全站动效暂停；修复离屏仍在运行的循环。
